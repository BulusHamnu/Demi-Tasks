# Demi Tasks Manager
A efficient task management application that allows you to organize your tasks, track progress, and analyze your productivity.

## Features
- **Task Management:** Create, edit, and delete tasks with ease.
- **To-Do List:** Create, edit, and delete tasks with ease.
- **Attachments:** Attach files to tasks for better organization.
- **Due Dates:** Set deadlines to stay on track.
- **Custom Categories:** Organize tasks using predefined and custom categories.
- **Dashboard Overview:** View tasks categorized by status and sorted by category.
- **Calendar Integration:** Uses Vanilla Calendar to display tasks.
- **Task Analysis:** Uses Chart.js to provide insights into completed and pending tasks.
- **Persistent Storage:** Tasks are stored using IndexedDB, allowing for large data storage, including files.
- **Future Enhancements:** A scheduling function and notifications will be added soon.

## Technologies Used
- HTML, CSS, JavaScript (Vanilla JS)
- IndexedDB (for storage)
- Vanilla Calendar (for task scheduling)
- Chart.js (for task analysis and statistics)
